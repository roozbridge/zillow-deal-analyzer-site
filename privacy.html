Privacy Policy

Last updated: May 29, 2026

Overview

Zillow Deal Analyzer is a Chrome extension for screening Zillow listings and search results for rental-investment analysis. The extension is designed to be local-first: saved deals, notes, assumptions, search snapshots, exports, and backup files stay in the user's browser unless the user exports or imports them.

Support contact: zillowextension@proton.me

Information Stored Locally In The Browser

The extension stores the following in Chrome local storage:

  • User assumptions and settings.
  • Saved property lists.
  • Saved property snapshots.
  • Search snapshots.
  • Notes and statuses attached to saved properties.
  • Dashboard state and onboarding checklist state.
  • Local usage counters.
  • Cached mortgage-rate data.
  • Supabase account session tokens when the user signs in.

This local data is stored in the user's browser profile. It is not intentionally sent to Zillow Deal Analyzer backend services in the current launch design.

Information Sent To Backend Services

When a user signs in or subscribes, the extension uses Supabase for account and entitlement services. The backend may process:

  • Account email.
  • Supabase authentication identifiers.
  • Backend profile identifier.
  • Stripe customer and subscription identifiers.
  • Subscription plan/status.
  • Monthly usage counters and usage events for gated features.
  • Rate-limit counters by backend profile, route, and minute window.

These backend records are used for authentication, subscription status, billing support, rate limiting, and enforcing Free/Pro plan limits.

Billing

Payments are handled by Stripe-hosted Checkout and Billing Portal pages. Zillow Deal Analyzer does not collect or store payment card numbers directly.

Stripe may process payment details, billing email, invoices, customer records, and subscription events. Stripe sends subscription lifecycle events to Supabase webhooks so the extension can determine whether the signed-in account has Free or Pro access.

Users can manage payment methods and cancel subscriptions through the Stripe Billing Portal.

Subscription terms and refund policy are maintained separately in the public subscription terms and refund policy. Stripe Checkout shows final price, tax, billing interval, and payment details before payment is submitted.

Zillow Page Data

The extension reads data from the Zillow page the user is viewing so it can calculate rental-investment estimates and display the in-page panel.

The current launch design does not intentionally send the following to Zillow Deal Analyzer backend services:

  • Raw Zillow HTML.
  • Raw Zillow search responses.
  • Saved property snapshots.
  • User notes.
  • Export files.
  • Backup files.

Mortgage Rate Data

The extension may request Freddie Mac PMMS data to estimate a baseline mortgage-rate assumption. Cached or fallback rate values may be stored locally in the browser.

Product Analytics And Telemetry

Automatic product-behavior telemetry is disabled for first launch.

Chrome Web Store may provide store-level analytics to the developer, such as installs, uninstalls, impressions, weekly users, and ratings. Stripe provides billing/subscription records for payment operations. Supabase stores backend usage counters required for gated feature enforcement.

The Chrome Web Store Privacy section includes "User activity" because signed-in backend usage counters record limited monthly counts for gated actions, such as exports, print reports, full-search export runs, and search rows analyzed. These counters are used for Free/Pro limit enforcement, rate limiting, billing support, and abuse prevention.

These usage counters are not broad browsing-history tracking. Zillow Deal Analyzer does not track user activity on unrelated websites and does not use usage counters for advertising profiles or credit/lending decisions.

The extension does not currently send broad product-behavior events such as tab clicks, saved-property details, search terms, raw listing content, or notes to a product analytics service.

Support, Refunds, And Account Deletion

For support, refunds, or backend account deletion requests, email zillowextension@proton.me.

The Account and Settings tabs may open a draft email to zillowextension@proton.me for support or feedback. These emails are user-initiated and editable before sending.

For account-specific support, include the signed-in account email. The Account tab may show a backend profile prefix to help identify the correct account.

Backend account deletion requests are handled manually for first launch. Backend deletion does not automatically erase local browser data such as saved lists, notes, search snapshots, exports, or backup files. Users who want to remove local data should clear it from the dashboard, remove the extension's browser data, or remove the browser profile.

Data Sharing

Zillow Deal Analyzer uses third-party service providers needed to operate the product:

  • Supabase for authentication, backend database, entitlement checks, usage counters, and Edge Functions.
  • Stripe for checkout, billing portal, payment processing, subscription records, and invoices.
  • Chrome Web Store/Google for extension distribution and store analytics.
  • Freddie Mac public pages for mortgage-rate baseline data when available.

Zillow Deal Analyzer does not sell user data.

Security

Backend calls use HTTPS. Stripe card collection is handled on Stripe-hosted pages. Server-side Stripe and Supabase service-role secrets are not included in the Chrome extension bundle.

Limited Use Statement

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

No Affiliation

Zillow Deal Analyzer is not affiliated with Zillow, Google, Chrome Web Store, Freddie Mac, Supabase, or Stripe.

Changes

This policy may be updated as the product changes. The published privacy policy shows the latest effective date.
