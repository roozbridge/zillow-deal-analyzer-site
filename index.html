What It Does

Listing Analysis

Estimate cashflow, DSCR, NOI, cap rate, break-even rent, and target price directly from a Zillow listing page.

Search Snapshots

Score visible or loaded Zillow search results, save candidates, and review partial rows later in a local dashboard.

Local Workflow

Save lists, compare deals, add notes and statuses, export CSV/XLSX files, print reports, and manage browser-local backups.

Privacy Position

Saved lists, notes, search snapshots, exports, backup files, and assumptions are stored in the user's browser profile unless the user exports or imports them. Sign-in and Pro subscription features use Supabase for account and entitlement services and Stripe-hosted pages for billing.
